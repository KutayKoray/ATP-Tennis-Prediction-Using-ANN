🧠 Behind the Scenes

How It Works

From player names to win probability in 4 steps — no TensorFlow, no PyTorch, just NumPy.

Step 01
🔍

Player Lookup

Search 65,000+ players across 57 years of ATP data. Match names to historical records.

Step 02
⚙️

Feature Engineering

Compute 37 features — career win rates, serve stats, head-to-head, surface performance, and more.

Step 03
📐

Normalization

StandardScaler normalization (mean=0, std=1) — critical for L2 regularization and model accuracy.

Step 04
🎯

Prediction

Forward propagation through 37→128→64→1 network with Leaky ReLU + Sigmoid outputs a win probability.

Network Architecture
2 Hidden Layer ANN — Built from scratch with NumPy
Input 37 features
Hidden 1 128 neurons Leaky ReLU
Hidden 2 64 neurons Leaky ReLU
Output 1 neuron Sigmoid
✨ No TensorFlow • No PyTorch • Pure NumPy

🔧 Under the Hood

Technical Details

Everything built from scratch — no ML frameworks used.

📊 37 Input Features

  • Career & surface win rates
  • Recent form (last 20 matches)
  • Serve stats (ace%, df%, 1st serve%)
  • Head-to-head record
  • Ranking points & age
  • Hand matchup encoding
  • Temporal features (month, quarter)
  • Surface one-hot encoding

⚙️ Training Configuration

  • Optimizer: Adam (β1=0.9, β2=0.999)
  • He weight initialization
  • L2 regularization (λ=0.5)
  • Learning rate: 0.003
  • Early stopping (patience=10)
  • StandardScaler normalization
  • Data: 195K+ ATP matches (1968–2024)
  • Test set: 2024 season

🛡️ Data Integrity

  • Strict chronological processing
  • No data leakage — stats from past only
  • Randomized P1/P2 assignment
  • Service stats from last 20 matches
  • Diff features removed (reveal winner)
  • Binary features skip normalization
  • Missing values → training median
  • H2H from encounters only
